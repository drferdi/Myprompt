# ADR-0001: Operate Prompt as a Standalone Electron Capsule

## Function

Records the portability decision that governs dependency and lifecycle boundaries.

## Decision

Sentra Prompt owns its source, package manifest, lockfile, workspace declaration,
Prisma schema/migrations, tests, build scripts, and verification commands. Required
lifecycle execution resolves from the capsule root and must work after extraction.

## Consequences

The capsule cannot depend on a parent workspace or sibling project. Credentials and
external systems remain explicit runtime dependencies. `verify:extraction` is the
decisive portability evidence.
