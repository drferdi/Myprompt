# Support

## Questions and bug reports

Open an issue on GitHub using the bug report or feature request template. Include
the Myprompt version, operating system, and the steps that reproduce the problem.
Never paste API keys, `.env` values, or personal data into an issue.

## Security issues

Do not report vulnerabilities in public issues. Follow the process in
[SECURITY.md](SECURITY.md).
