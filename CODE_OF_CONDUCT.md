# Code of Conduct

## Our pledge

We are committed to a welcoming, respectful, and harassment-free community for
everyone who participates in this project.

## Expected behaviour

- Use respectful and inclusive language.
- Give and receive technical feedback constructively.
- Focus discussion on the work and its evidence.
- Respect privacy, security boundaries, and confidential information.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, deliberate disclosure of
private information, and attempts to bypass security controls are not acceptable.

## Reporting

Report concerns privately to the project maintainers or through GitHub Security
Advisories when the matter involves a security issue. Reports will be handled with
discretion.
